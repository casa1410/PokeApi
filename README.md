# PokeApi

PokeApp es una aplicación **SSR con Next.js 14** que implementa autenticación con roles, protección de rutas y renderizado híbrido (cliente/servidor).  
Permite visualizar una **Pokédex** filtrable por generación y acceder a los detalles de cada Pokémon con sus datos principales.

---

##  1. Instrucciones para instalar y ejecutar el proyecto

###  Requisitos previos
- Node.js **>= 18**
- npm o yarn

###  Instalación
```bash
# Clonar el repositorio
git clone https://github.com/tuusuario/my-pokeapp.git
cd my-pokeapp

# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Abrir en el navegador
http://localhost:3000

# Ejecutar pruebas unitarias
npm test
